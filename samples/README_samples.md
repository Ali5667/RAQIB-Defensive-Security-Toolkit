# 📂 samples/ — بيانات تجريبية لاختبار الأدوات

هذا المجلد يحتوي بيانات **اصطناعية مولّدة عشوائياً** (مو بيانات حقيقية من أي نظام) لتجربة أدوات RAQIB مباشرة بدون الحاجة لملفات لوج حقيقية من جهازك.

| الملف | الحجم | يُستخدم مع |
|---|---|---|
| `sample_auth.log` | ~1.4MB | تقرير SSH الفاشل، كاشف Brute Force، مراجعة سجل Sudo، بحث كلمة مفتاحية |
| `sample_access.log` | ~1.4MB | محلل سجلات الويب (Web Access Analyzer) |
| `sample_suspicious_binary.bin` | ~2MB | حاسبة Hash، محدد نوع الملف، مستخرج النصوص المشبوهة، حاسبة الإنتروبيا |

### مثال تجربة سريعة
1. شغّل `./raqib.sh`
2. اختر **تحليل السجلات → تقرير محاولات SSH الفاشلة**
3. أدخل مسار: `samples/sample_auth.log`

أو لأدوات المالوير:
1. اختر **تحليل الملفات المشبوهة → مستخرج النصوص المشبوهة**
2. أدخل مسار: `samples/sample_suspicious_binary.bin`

> ⚠️ هذه بيانات وهمية بالكامل لأغراض الاختبار فقط، لا تحتوي أي معلومات حقيقية أو كود ضار فعلي.
