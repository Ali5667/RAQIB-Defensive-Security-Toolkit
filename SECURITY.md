# Security Policy

RAQIB is a defensive security tool. Vulnerabilities in the tool itself are taken seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| 2.0.x   | :x:                 |
| < 2.0   | :x:                 |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report privately via one of:
- GitHub: open a [private security advisory](https://github.com/Ali5667/RAQIB-Defensive-Security-Toolkit/security/advisories/new) on this repository.
- X (Twitter): DM [@ali_cys45](https://twitter.com/ali_cys45)

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce (a minimal proof of concept, if possible)
- The RAQIB version and OS/environment you tested on

You can expect an initial response within a few days. Once a fix is confirmed,
credit will be given in the release notes unless you prefer to remain anonymous.

## Scope Notes

RAQIB's scanning tools (ports, vulnerabilities, permissions) are intended
**exclusively for systems and networks you own or are explicitly authorized to test.**
Misuse of these tools against systems you do not have authorization for is outside
the scope of this project and the sole responsibility of the user.
