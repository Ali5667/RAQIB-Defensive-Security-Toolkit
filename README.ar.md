## 📖 نظرة عامة

**رقيب (RAQIB)** هي مجموعة أدوات أمنية دفاعية، صُممت خصيصًا للفرق الزرقاء (Blue Teams)، ومستجيبي الحوادث، ومهندسي الأمن الذين يحتاجون إلى *نتائج فورية وموثوقة* — على خوادم محصنة دون الحاجة لتثبيت أي برمجيات إضافية.

كل أداة مكتوبة من الصفر بالاعتماد على أدوات POSIX الأساسية (`ss`, `find`, `awk`, `grep`, `openssl`, `/dev/tcp`, مكتبة `python3` القياسية). لا يوجد Nmap. لا يوجد Wireshark. ولا أي برامج أمنية خارجية. مجرد أكواد برمجية نظيفة وقابلة للتدقيق وتعمل حتى على حاوية Alpine مبسطة أو خادم مغلق تمامًا.

58 أداة موزعة على 8 مجالات تشغيلية، **مرتبطة معًا كمسار عمل متكامل للاستجابة للحوادث** — وليس مجرد مجموعة نصوص برمجية (scripts) متفرقة.

> ⚠️ **للاستخدام المصرح به فقط.** أدوات الفحص مخصصة للاستخدام على *بنيتك التحتية الخاصة* أو الأنظمة التي تملك تصريحاً كتابياً صريحاً بتقييمها.

## ⚙️ البدء السريع

```bash
# استنساخ المستودع
git clone https://github.com/Ali5667/RAQIB-Defensive-Security-Toolkit.git
cd RAQIB-Defensive-Security-Toolkit

# التشغيل (يتطلب Bash 4+ — انظر الملاحظة لمستخدمي macOS)
chmod +x raqib.sh
./raqib.sh

# لأجهزة macOS استخدم الأوامر التالية:
# brew install bash && /opt/homebrew/bin/bash raqib.sh
```

### المتطلبات

| المتطلب | ملاحظات |
|---|---|
| **Bash 4+** | نظام macOS يأتي افتراضياً مع Bash 3 — قم بتثبيت التحديث `brew install bash` |
| **Python 3.8+** | لمستوى الإنتروبيا (entropy)، محرك الذكاء، التشفير، وتصدير SIEM |
| `find`, `awk`, `grep`, `ss`, `openssl` | أدوات أساسية — متواجدة على أي نظام Linux |
| `curl` *(اختياري)* | فحوصات السمعة، تحديثات القواعد، تنبيهات Telegram |
| `yara` *(اختياري)* | لتمكين طبقة YARA الحقيقية فوق محرك YARA-lite |
| `python3 cryptography` *(اختياري)* | لتشفير التقارير (AES-256-GCM) |

## 🛠️ حل المشاكل الشائعة (Troubleshooting)

| المشكلة | السبب والحل |
|---|---|
| **ظهور رسالة `Permission denied` عند التشغيل** | السكربت لا يمتلك صلاحيات التشغيل. قم بتشغيل الأمر: `chmod +x raqib.sh`. |
| **أخطاء في بناء الجملة (Syntax errors) على نظام macOS** | يأتي نظام macOS افتراضيًا بإصدار قديم (Bash 3)، ولكن الأداة تتطلب Bash 4 فما فوق. **الحل**: قم بتثبيت إصدار أحدث باستخدام الأمر `brew install bash` ثم شغل الأداة عبر `/opt/homebrew/bin/bash raqib.sh`. |
| **الأحرف العربية تظهر كعلامات استفهام `?` أو مربعات** | الطرفية (Terminal) لا تدعم تشفير UTF-8. **الحل**: استخدم طرفية حديثة تدعم اللغة العربية مثل Windows Terminal أو iTerm2 أو GNOME Terminal، وتأكد من أن لغة النظام تدعم UTF-8 (مثال: `export LANG=ar_AE.UTF-8`). |
| **فشل عملية التشفير أو فك التشفير** | مكتبة `cryptography` في بايثون غير مثبتة. **الحل**: قم بتثبيتها باستخدام `pip3 install cryptography` أو عبر مدير الحزم الخاص بنظامك (`sudo apt install python3-cryptography`). |

## ⚠️ قيود معروفة

شفافية تامة، وليس تسويقًا:
- **تحليل ثابت فقط.** لا يوجد وضع تنفيذ ديناميكي (Sandboxing) حتى الآن — موجود ضمن الخطط المستقبلية.
- **لا توجد ملفات `.yar` مرفقة مع المشروع.** البرنامج يشغل YARA حقيقي، ولكن يتوجب عليك توفير القواعد (Rules) الخاصة بك.
- **الاختبار الأساسي تم على Debian/Ubuntu و Kali.** قد تحتاج بعض التوزيعات الأخرى إلى تعديلات طفيفة.
- **الاعتماد على التحديثات الحية معطل افتراضيا** (`enabled=0`) — يجب توجيهها لمصدر تتحكم به وتثق به.
