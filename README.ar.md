## 📖 نظرة عامة

**رقيب (RAQIB)** هي مجموعة أدوات أمنية دفاعية، صُممت خصيصًا للفرق الزرقاء (Blue Teams)، ومستجيبي الحوادث، ومهندسي الأمن الذين يحتاجون إلى *نتائج فورية وموثوقة* — على خوادم محصنة دون الحاجة لتثبيت أي برمجيات إضافية.

كل أداة مكتوبة من الصفر بالاعتماد على أدوات POSIX الأساسية (`ss`, `find`, `awk`, `grep`, `openssl`, `/dev/tcp`, مكتبة `python3` القياسية). لا يوجد Nmap. لا يوجد Wireshark. ولا أي برامج أمنية خارجية. مجرد أكواد برمجية نظيفة وقابلة للتدقيق وتعمل حتى على حاوية Alpine مبسطة أو خادم مغلق تمامًا.

97 أداة ومحرك أمني وتحليلي موزعة على 8 مجالات تشغيلية (73 أداة ومحركاً دفاعياً + 24 أداة في وضع التحديات CTF)، **مرتبطة معًا كمسار عمل متكامل للاستجابة للحوادث** — وليس مجرد مجموعة نصوص برمجية (scripts) متفرقة. وبدءاً من هذا الإصدار تعمل الأدوات أيضاً على **ويندوز بشكل أصلي** (Git Bash / WSL2) وعلى macOS: تشمل حزمة دفاع ويندوز الأصلية فحوص جدار الحماية، اتصالات TCP وربطها بالعمليات، أحداث تسجيل الدخول الفاشلة (4625)، المهام المجدولة وWindows Defender — كلها عبر PowerShell حصراً.

> ⚠️ **للاستخدام المصرح به فقط.** أدوات الفحص مخصصة للاستخدام على *بنيتك التحتية الخاصة* أو الأنظمة التي تملك تصريحاً كتابياً صريحاً بتقييمها.

## ⚙️ البدء السريع

### لينكس / Kali / WSL2

```bash
# استنساخ المستودع
git clone https://github.com/Ali5667/RAQIB-Defensive-Security-Toolkit.git
cd RAQIB-Defensive-Security-Toolkit

# إعطاء صلاحية التشغيل والبدء
chmod +x raqib.sh
./raqib.sh

# لأجهزة macOS:
# brew install bash && /opt/homebrew/bin/bash raqib.sh
```

### ويندوز (أصلي — بدون الحاجة لـ WSL)

```bat
:: شغّل raqib.bat بالنقر المزدوج، أو من cmd:
git clone https://github.com/Ali5667/RAQIB-Defensive-Security-Toolkit.git
cd RAQIB-Defensive-Security-Toolkit
raqib.bat
```

المُشغّل يبحث تلقائياً عن Git Bash (يُنصح بتثبيت Git for Windows)، ويفحص النظام أصلياً عبر PowerShell: ملفات جدار الحماية الشخصية، منافذ الاستماع، ربط TCP↔العملية، أحداث تسجيل الدخول الفاشلة (4625)، استمرارية المهام المجدولة، حالة Windows Defender ومفاتيح بدء التشغيل. الأدوات التي تحتاج لينكس (`/proc`, systemd, iptables) تخرج برسالة عربية/إنجليزية واضحة تشرح البديل — أو شغّل كل شيء داخل WSL2.

12. **إعداد عميل التجميع (Collector Client Setup)**: ربط جهاز العميل ليرسل أحداثه للمركز.

### 🚨 كشف التطفل (8)

2. **مدقق المنافذ المفتوحة**: ربط كل منفذ بالعملية المسؤولة عنه عبر `ss`/`lsof`.
3. **مراقب سلامة الملفات (FIM)**: إنشاء خط أساس بتجزئة SHA256 واكتشاف التعديلات.
4. **مدقق المهام المجدولة (Cron Auditor)**: فحص وتنبيه لأي مهام Cron مضافة أو معدلة حديثاً.
5. **مراقب معدل الاتصال**: مقارنة لقطتين متتاليتين لرصد الارتفاع المفاجئ في الاتصالات.
6. **حاظر العناوين (IP Blocker)**: إدراج قواعد حظر في UFW أو iptables أو nftables مع التوثيق.
7. **كاشف بصمات TLS وبصمات C2 (TLS Fingerprint Detector)**: استخلاص بصمات JA3/JA4 من حزم Client Hello وكشف اتصالات أطر الهجوم المشهورة (Cobalt Strike, Metasploit, Sliver, Havoc).
8. **محدد المعدل المتكيف وحفرة القطران (Adaptive Rate Limiter & Tarpit)**: دفاع متدرج متكيف (تحذير ← خنق المعدل ← Tarpit تبطيء المهاجم ← حظر كامل) يدعم nftables و iptables.

### 🦠 تحليل البرمجيات الخبيثة (15)
1. **حاسبة الـ Hash**: استخراج MD5 و SHA1 و SHA256 مع إمكانية التحقق من السمعة مباشرة.

6. **الحجر والاستئصال**: حجر الملفات ومطابقة النسخ المتطابقة بالـ Hash وحذفها بشكل آمن.
7. **المنظف التلقائي للمالوير**: مسح شامل للشيلات والكرون الخبيث ومجلدات `/tmp`.
8. **فاحص سمعة الـ Hash**: استعلام من VirusTotal و MalwareBazaar.
9. **ماسح YARA-lite**: محرك فحص تراكمي بالأوزان ونسب دقة F1 تصل إلى 98.5%.
10. **محدّث القواعد الحي**: سحب قواعد الفحص بأمان مع التأكد من التنسيق وحفظ النسخ الاحتياطية.
11. **الاستعلام عن معلومات التهديد (Threat Intel)**: محرك محلي يستعلم بدون إنترنت عن مؤشرات الاختراق.
12. **فرز الملفات المجهولة**: نقاط ترجيحية وتفسير كامل لكل إشارة اشتباه.
13. **كاشف الروتكيت (Rootkit Detector)**: كشف العمليات المخفية بين `/proc` و `ps`، الملفات العاملة من الذاكرة `memfd`، وحدات الكيرنل المخفية، خطافات eBPF، وملفات `ld.so.preload`.
14. **مصنف تعلم الآلة الخفيف (ML Classifier)**: شجرة قرارات وزنية (16 ميزة هندسية) + مصنف Naive Bayes غاوسي بدون أي مكتبات خارجية (Pure Python) مع إمكانية التدريب الذاتي على خط الأساس.
15. **مترجم قواعد سيجما (Sigma Translator)**: محلل YAML مدمج يحول قواعد Sigma الكشفية إلى تعبيرات regex سريعة لـ `grep` أو صيغة YARA-lite المدمجة في رقيب.

| الفحص الفرعي | ماذا يفعل |
|---|---|

| 🔗 **الاتصالات ↔ العملية** | `Get-NetTCPConnection` + `Get-Process` — رصد الاتصالات القائمة بعناوين خارج LAN لمراجعتها عبر ذكاء التهديدات |
| 🚨 **فرز تسجيل الدخول الفاشل** | الحدث 4625 خلال آخر 48 ساعة — ترتيب عناوين المهاجمين بأعمدة الخطورة؛ الحدود 20/100/500 → متوسط/عالي/حرج |
| ⏰ **استمرارية المهام المجدولة** | إجراءات تنفّذ من TEMP/مسارات قابلة للكتابة أو LOLBins (`-enc`, `mshta`, `regsvr32`, `.vbs`...) |
| 🛡️ **حالة Defender** | مضاد الفيروسات + الحماية اللحظية، عمر التوقيعات، علم الفحص الجارٍ، آخر 10 تهديدات من `Get-MpThreatDetection` |

كل الاكتشافات تتدفق عبر خط `finding_add` الموحد → `.raqib_events.jsonl` / ارتباط SIEM / تنبيهات تيليجرام، مع تقرير `windows_defense_scan.txt`.

## 🚀 محركات وأدوات التحليل المتقدمة الجديدة (v2.2 New Engines)

### 1. مصنف تعلم الآلة الخفيف (`tools/malware/ml_classifier.py`)
- **التقنية**: شجرة قرارات موزونة (Weighted Decision Tree) بـ 16 خاصية مستخلصة (إنتروبيا، تعتيم الأوامر، نصوص الاتصال العكسي، أقسام ELF، تعبئة UPX) مدمجة مع مصنف **Naive Bayes غاوسي**.
- **المزايا**: تصنيف الملفات المشبوهة، فحص مجلدات كاملة، تدريب ذاتي على خط أساس نظيف، وإصدار أحكام تفسيرية واضحة بنظام التصويت المشترك (Ensemble Voting).
```bash
# تصنيف ملف مشبوه
python3 tools/malware/ml_classifier.py classify /path/to/suspect_file

# فحص مجلد كامل واستخراج تقرير ملخص
python3 tools/malware/ml_classifier.py classify-dir /var/www/html/ --json

# تدريب المصنف على مجلد ملفات نظام نظيفة كخط أساس

```

### 2. مترجم قواعد سيجما (`tools/malware/sigma_translator.py`)

- **المزايا**: تحويل قواعد Sigma الشائعة إلى أوامر `grep -iE` مباشرة للبحث في سجلات لينكس (Auth, Syslog, Nginx, Apache)، أو تحويلها لقواعد YARA-lite المدمجة في رقيب.
```bash
# ترجمة قاعدة Sigma إلى أمر grep وأمر بحث مباشر في السجلات
python3 tools/malware/sigma_translator.py rule.yml

# تحويل القاعدة إلى صيغة YARA-lite المعتمدة في رقيب
python3 tools/malware/sigma_translator.py rule.yml --format yara-lite

# ترجمة مجلد كامل من القواعد وفحص سجل النظام فوراً
python3 tools/malware/sigma_translator.py ./sigma_rules/ --scan /var/log/auth.log

### 4. محدد المعدل المتكيف وحفرة القطران (`tools/ids_ips/adaptive_rate_limiter.sh`)

```

## 🛡️ دليل كاشف الروتكيت (Rootkit Detector)

*(مدمج من [`tools/malware/rootkit_detector.md`](tools/malware/rootkit_detector.md))*

محرك فحص تجريدي للقراءة فقط لكشف الروتكيت والأنوية الخفية بدون أي تبعيات خارجية وبأدوات POSIX القياسية فقط:

### ماذا يفحص ولماذا؟

| الفحص | ما الذي يتم فحصه | لماذا يعد مهماً |
|---|---|---|
| `hidden_processes` | مقارنة كل معرّف PID في `/proc` مع ناتج `ps -e` | إذا وجد PID في `/proc` وغير مرئي في `ps` فهذا يعني وجود خطاف روتكيت لإخفاء أنشطة المهاجم. |
| `tampered_ps_output` | وجود عمليات في `ps` غير موجودة فعلياً في `/proc` | يشير إلى أن أداة `ps` نفسها تم استبدالها أو التلاعب بها. |
| `unreadable_procs` | عجز المستخدم root عن قراءة `/proc/<pid>/status` | الروتكيت على مستوى الكيرنل (LKM) يقوم بحجب قراءة ملفات الحالة لمنع كشفه. |
| `running_deleted_binary` | إشارة `/proc/<pid>/exe` إلى `(deleted)` | عملية مستمرة بالعمل بعد حذف ملفها من القرص — أسلوب كلاسيكي للمهاجمين لإخفاء الأثر. |
| `memfd_execution` | إشارة `/proc/<pid>/exe` إلى `memfd:` | تشغيل ملف تنفيذي مباشرة من الذاكرة دون كتابته على القرص نهائياً (Fileless). |
| `executable_from_temp` | تشغيل ملف تنفيذي من `/tmp` أو `/dev/shm` أو `/var/tmp` | البرمجيات الخبيثة تقوم بإنزال أدواتها وتشغيلها عادة من المجلدات المتاحة للجميع. |
| `empty_cmdline` | عملية بمساحة المستخدمين تمتلك سطر أوامر `cmdline` فارغ | محاولة للتخفي والاندماج ضمن خيوط عمل الكيرنل (Kernel Threads). |
| `hidden_kernel_module` | وجود أقسام لوحدة في `/sys/module/` وغيابها من `/proc/modules` | أسلوب التخفي الأبرز لروتكيتات LKM (حيث أن `lsmod` يقرأ من `/proc/modules` ويضلل المشغل). |
| `unowned_preload_lib` | التحقق من تبعية مكتبات التحميل المسبق عبر `dpkg` أو `rpm` | حقن مكتبة غير معرّفة بحزم النظام في كافة العمليات هو جوهر عمل الروتكيت في مساحة المستخدم. |
| `hidden_temp_executable` | ملفات تنفيذية مخفية تبدأ بنقطة في المجلدات المؤقتة | تتفادى العرض في الأوامر البسيطة و `/var/tmp` لا يُمسح مع إعادة التشغيل. |
| `suspicious_kernel_module` | فحص أسماء وحدات الكيرنل مقابل قائمة الروتكيتات المشهورة | مطابقة برمجيات شهيرة مثل diamorphine و reptile و suterusu وغيرها. |
| `module_file_missing` | وحدات كيرنل محملة دون وجود ملف `.ko` لها في مسار النواة | وحدة تم تحميلها وحذف ملف المصدر فوراً لعدم إمكانية تحليلها لاحقاً. |
| `ld_so_preload` | فحص وجود ومحتوى ملف `/etc/ld.so.preload` | إجبار النظام على تحميل مكتبة معينة مع كل ملف تنفيذي يتم تشغيله. |
| `env_ld_preload` | فحص متغيرات `LD_PRELOAD` في بيئة العمل وملفات بدء التشغيل | خطاف يتم تثبيته ليعمل مع كل جلسة للمستخدم أو النظام. |
| `altered_system_binary` | فحص مطابقة التجزئة عبر `dpkg --verify` أو `rpm -Va` | اكتشاف استبدال أدوات النظام الأساسية (مثل ls, ps, netstat) بأدوات ملوثة. |
| `unprivileged_bpf_enabled` | التحقق من قيمة `kernel.unprivileged_bpf_disabled` | تمكين أي مستخدم غير مرخص من تحميل كود BPF — بوابة روتكيتات eBPF الحديثة. |
| `bpf_kprobe_attached` | فحص خطافات kprobe/tracepoint عبر `bpftool` | روتكيتات eBPF تعمل بدون أي ملف `.ko` ولا تظهر في `lsmod` إطلاقاً. |
| `pinned_bpf_objects` | كائنات BPF المثبتة في مسار `/sys/fs/bpf` | الكائنات المثبتة تظل نشطة حتى بعد توقف العملية الأم ويتم تحميلها عند الإقلاع. |

### أوامر التشغيل
```bash
# التشغيل التفاعلي القياسي
sudo bash tools/malware/rootkit_detector.sh

# التشغيل مع إخراج بصيغة NDJSON للمعالجة الآلية
sudo bash tools/malware/rootkit_detector.sh --json

# مساعدة
bash tools/malware/rootkit_detector.sh --help
```

## 📧 دليل محلل ترويسات البريد (Email Header Analyzer)

*(مدمج من [`tools/forensics/email_header_analyzer.md`](tools/forensics/email_header_analyzer.md))*

أداة تكتيكية لتحليل ترويسات رسائل البريد الإلكتروني لكشف محاولات التصيد والاحتيال وانتحال الهوية (BEC). تعمل كلياً عبر مكتبات بايثون القياسية — **دون أي اتصال بالإنترنت ودون تسريب أي بيانات خارج الجهاز**.

### ماذا يفحص المحلل؟
- **فحوصات التوثيق**: التحقق من سجلات SPF و DKIM و DMARC بدقة، وتحديد أسباب الفشل أو عدم المحاذاة.
- **سلسلة الترحيل (Received Chain)**: رصد التلاعب في أزمنة التنقل بين الخوادم وتحديد المصادر المشبوهة أو القادمة من شبكات داخلية مزورة (RFC1918).
- **عدم تطابق النطاقات**: كشف الخداع عندما يختلف نطاق المرسل `From` عن مسار الرجوع `Return-Path` أو عندما يتم تحويل الردود سراً إلى نطاق مختلف تماماً عبر `Reply-To`.
- **انتحال الاسم الظاهر (Display Name Spoofing)**: كشف إدخال علامات تجارية كبرى في الاسم المرئي بينما البريد الحقيقي مختلف تماماً.
- **مراسلو الحسابات المجانية**: تنبيه حرج عند إرسال فواتير أو مطالبات مالية من حسابات بريد مجانية مثل Gmail أو Hotmail.
- **الكلمات المفتاحية للتصيد**: تقييم الضغط النفسي واستعجال الضحية (مثل: "حسابك مهدد بالإغلاق"، "تأكيد الهوية فوراً").

### أوامر التشغيل
```bash
# تقرير تحليلي لملف بريد
python3 tools/forensics/email_header_analyzer.py suspicious.eml

# إخراج بصيغة NDJSON
python3 tools/forensics/email_header_analyzer.py --json suspicious.eml

# قراءة البريد مباشرة من التدفق المعياري stdin
cat suspicious.eml | python3 tools/forensics/email_header_analyzer.py -
```

## 🧠 محرك استخبارات التهديدات (SQLite و MITRE ATT&CK)

يحتوي رقيب على محرك استخبارات تهديدات محلي مدمج وسريع يعمل بقاعدة بيانات **SQLite مع تفعيل نمط WAL (Write-Ahead Logging)** لتمكين الفحص المفسَّر والمطابقة السلوكية بدون اتصال بالإنترنت أثناء الاستجابة للحوادث:

### 🌐 مصادر التهديدات وفترة الصلاحية (TTL)
| المصدر | النوع | المعالجة والتحقق | فترة الصلاحية والتردد |
|---|---|---|---|
| **Feodo Tracker** | عناوين C2 المشبوهة | ملف JSON عام يُفحص بصرامة عبر مكتبة `ipaddress` (استبعاد العناوين الخاطئة، الحلقية Loopback، والمتعددة Multicast) | **صلاحية 30 يوماً** (تنظيف تلقائي للمنتهية)؛ يتحدث كل **24 ساعة** |
| **MITRE ATT&CK** | عائلات البرمجيات الخبيثة والتقنيات | حزمة STIX 2.x للمؤسسات؛ تتجاهل العناصر المسحوبة (`revoked`) والمهجورة (`x_mitre_deprecated`) | تتحدث كل **7 أيام** |

### 🔒 قاعدة الدمج وحماية السجلات المعتمدة (`verified=1`)
- **حظر الكتابة فوق السجلات المعتمدة**: أي صف لعائلة مالوير أو سلوك تقني يحمل `verified = 1` يعتبر **محمياً بشكل دائم وغير قابل للتعديل التلقائي**. المزامنة لا تكتب فوقه أبداً.
- **جداول التحضير (Staging)**: تدخل البيانات الجديدة أولاً في جداول عزل (`staging_ioc_ips`, `staging_malware_families`, `staging_malware_behaviors`) بقيمة `verified = 0` ولا تنتقل إلى الجداول الرئيسية إلا بعد اجتياز كامل الفحوصات بنجاح.

### 🛡️ الفحص الصارم قبل النقل (Pre-Flight Checks)
لضمان أمان النظام واستقراره، لا يتم ترحيل أي بيانات من الـ Staging إلى الإنتاج إلا بعد اجتياز الفحوصات التالية:
1. **بروتوكول آمن فقط**: الاتصال عبر **HTTPS فقط**؛ ويتم رفض أي رابط `http://` أو غير مشفر فوراً.
2. **حد أقصى لحجم التنزيل**: إيقاف التنزيل فوراً إذا تجاوز الحجم المسموح (30 ميغابايت لـ Feodo، و120 ميغابايت لـ ATT&CK) لحماية الذاكرة والقرص.
3. **مهلة زمنية صارمة**: حد أقصى للاتصال والاستجابة (35 ثانية).
4. **تدقيق الصيغة**: التأكد من صحة كود JSON واحتوائه على عناصر صالحة قبل أي عملية نقل.
5. **تراجع ذري وسجل تدقيق**: عند فشل أي فحص، يتم تفريغ جداول الـ Staging فوراً، ولا يُمس جدول الإنتاج، ويسجل الخطأ بالتفصيل في `update_log`.

### 🚀 التشغيل المباشر وقفل التزامن (Lock File)
يمتلك المحرك ملف قفل حصري (`raqib_update.lock`) لمنع تشغيل عمليتي تحديث في آن واحد:

```bash
# تحديث كافة المصادر (يتجاوز المصادر التي حُدثت مؤخراً)
raqib update --source all

# فرض تحديث Feodo Tracker فقط وتجاوز شرط الحداثة
raqib update --source feodo --force

# فرض تحديث MITRE ATT&CK فقط
raqib update --source attack --force

# البحث عن عنوان IP ومطابقته مع العائلة وسلوكيات ATT&CK
raqib lookup 198.51.100.14

# عرض إحصائيات القاعدة وسجل التحديثات
raqib status
```

### ⚙️ التشغيل التلقائي بالخلفية عبر systemd
تتوفر ملفات خدمة ومؤقت خلفي مخصصة لأنظمة Kali Linux و Debian و Ubuntu:

```bash
sudo cp tools/systemd/raqib-update.* /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now raqib-update.timer
```

### 🔍 المطابقة والتحليل السلوكي (بدون حكم قطعي)
عند فحص أي عنوان IP، يرجع النظام العائلة والمصدر وتاريخ الرصد وسلوكيات MITRE ATT&CK المرتبطة:
- **العائلة التي لا تملك ملف سلوك ترجع**: `"unknown"`.
- **الحكم غير قطعي**: النتيجة تقدم سياقاً استخباراتياً وتطابقاً ملاحظاً ولا تصدر حكماً إدانياً نهائياً مطلقاً. ينبغي على المحلل مراجعة سجلات النظام قبل اتخاذ إجراءات العزل.

### ⚠️ القيود والحدود الفنية
- **غياب المؤشر لا يعني سلامة العنوان**: قد تكون البنية التحتية للمهاجم جديدة كلياً أو لم تُرصد بعد.
- **تغير عناوين C2 السريع**: تتغير خوادم القيادة والتحكم أو يتم تحويلها (Sinkholed) بشكل دوري.
- **التشغيل بدون إنترنت**: في البيئات المعزولة، يمكن تمرير ملفات العينات المحلية عبر الراية `--offline`.

## 🛠️ حل المشاكل الشائعة

| المشكلة | السبب والحل |
|---|---|
| **رسالة `Permission denied`** | السكربت بحاجة لصلاحية تشغيل: نفذ `chmod +x raqib.sh`. |
| **أخطاء Syntax على macOS** | نظام macOS يأتي بـ Bash 3 القديم. الحل: ثبت إصداراً حديثاً `brew install bash` وشغل عبر `/opt/homebrew/bin/bash raqib.sh`. |
| **ظهور الأحرف كعلامات استفهام `?`** | الطرفية لا تدعم UTF-8. استخدم طرفية تدعم العربية كـ Windows Terminal أو iTerm2 وتأكد من ضبط `export LANG=ar_AE.UTF-8`. |
| **فشل تشفير أو فك تشفير التقارير** | مكتبة cryptography غير مثبتة. نفذ: `sudo apt install python3-cryptography` أو `pip3 install cryptography`. |

## ⚠️ قيود معروفة

شفافية تامة، وليس تسويقًا:
- **تحليل ثابت فقط.** لا يوجد وضع تنفيذ ديناميكي (Sandboxing) حتى الآن.
- **لا توجد ملفات `.yar` مرفقة.** البرنامج يدعم YARA الحقيقي عند توفره، لكن يجب عليك تزويده بقواعدك الخاصة.
- **الاختبار الأساسي تم على Debian/Ubuntu و Kali.**
